# Security

Do not post API keys, uploaded photographs, or exploit details in public issues.
Use GitHub's **Report a vulnerability** option if enabled; otherwise contact a
repository maintainer privately before sharing sensitive details.

The deployed paid-AI routes are intentionally disabled in the audited revision.
Manual discovery, matching, pricing, room photographs/calibration, and 3D planning
work without credentials. This safeguard takes effect only after an owner deploys
the change; opening a PR does not secure an older live deployment.

See [the security and cost audit](docs/SECURITY_AUDIT.md) for findings, verification
limits, account controls, and prerequisites for any future public AI launch.
No absolute security or cost guarantee is made.
